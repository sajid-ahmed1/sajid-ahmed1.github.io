# How I Update the Second Brain

Andrew Karpathy made a point recently that stuck with me: everyone should have a personal LLM wiki. The idea is simple. You do what humans do best, being creative, exploring ideas, having opinions and personal takes on things. Then you let AI do what it does best, summarising and recording those thoughts without the drag of sitting down to write structured documentation that nobody enjoys creating.

I've been using Anthropic's Claude Code for a while now but I only recently discovered its true power for this exact workflow. Before, updating a personal site or wiki meant context switching. Open the editor, find the right file, write the markdown, check the formatting, commit, push, wait for deploy. The friction was enough that half my ideas never made it out of my head.

Now? I think of a concept or learn something new about the tech industry, I journal it out as a quick note in my own words, and Claude updates my personal wiki within a couple of minutes. New category? Done. New post with tags, proper formatting, manifest entry? Done. It handles the boring structural stuff while I focus on the actual thinking.

This is what true personal AI assistance should be in my opinion. Not some chatbot answering trivia questions. An actual tool that removes the friction between having a thought and publishing it somewhere useful.

## How am I using it right now?

Well, you're reading this whilst I type it into the Claude Code input box. I'm on the sofa in Cambridge, sweating through this summer heatwave, and instead of opening VS Code and faffing about with JSON manifests I'm just writing. Claude handles the rest.

The barrier to adding to your own knowledge base should be as low as sending a text message. That's where we're at now and I genuinely think most people haven't realised it yet.
