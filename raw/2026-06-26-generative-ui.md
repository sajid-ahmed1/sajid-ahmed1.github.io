# [2026-06-26] ingest | The Balancing Act Between Intuitive UI and Chatbot Agents — Generative UI

**Source:** https://youtu.be/f32W5BEzWN0?is=lPv1yNpQoh6k9Esc
**Type:** Video reaction / personal take
**Ingested by:** Claude Code

---

I always thought chatGPT and Claude were too far in the spectrum. Yes I like chat interface for certain tasks but the gen Z unanimously agrees that any adult purchases like sofas or flights must be booked on a laptop - we can't trust those small phone screens. So it makes you wonder, if theres certain things that makes sense to be chatbot and agentic flows, and others on simple ui buttons and sliders, whats the middle ground?

I remember watching a document on Apple founders Steve Jobs and Steve Wozniak. They went to visit Xerox to see the first example of a GUI - a Graphical User Interface. Before then, it was all TUI (terminal user interfaces), writing code via a terminal. When GUIs came about, the market transformed and applications were created. 

I find a similar archetype with chatbots and agents. We've reached the TUI stage where we interact with these models in Claude Code but the middle ground would be UI that's simple in design and for more complex matters we ask the chatbot to generate a UI that fits our description. 

Harder more complex tasks can be completed by agentic flows. I've been there, trying to learn Photoshop with its millions of dropdowns and sub dropdowns just to get an image to overlay on another. This has somewhat been eradicated with agents who have the knowledge to traverse through those menu dropdowns naturally and execute on demand. However, for those moments where we want to visually confirm and interact with concepts or ideas, it shouldn't be a fixed UI we should be playing with but a generative UI. One that tweaks to our demands for those super niche or complex tasks.

The video explains a nice example of this. Whilst studying for my D200 exam, I was struggling to visualise how the chain rule in a gradient descent works. What nodes are updates or which weights. I wanted a Youtube style animation but something I can interact with. There came Claude with a interactive html file where I could mess around and understand how each piece of the neural network updated. The video points out Google Search which will now generate UI if the user requires a little more visual aspects of their tasks.

Still very early days of this concept but I believe this is the correct movement forward. The middle ground between boring chatbot interactions and fixed hard to navigate user interfaces - the generative user interface. How will I be exploring this idea? I'm not sure yet but I wanted to note this down and keep it in the backlog for my next opportunity!
